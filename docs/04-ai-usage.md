# 04 AI 辅助使用记录

## 使用范围

本项目允许使用 AI 辅助。本次初始版本由 Codex 协助完成以下工作：

- 将题目拆分为模型决策层、业务工具层和强制约束层；
- 生成 Python 项目骨架、核心循环、CLI 和 OpenAI 兼容接口；
- 生成合成素材、规则、排期与失败注入数据；
- 编写自动化测试、示例生成脚本和项目文档；
- 执行测试并抽查冲突、重复保存和保存失败 Trace。

AI 没有调用真实模型服务，没有创建 GitHub 仓库，也没有替候选人声称线上验证成功。

## 候选人贡献

截至当前版本，候选人提供了完整考核要求并选择第 1 题。核心实现和初始文档主要由 AI 生成。候选人在提交前应亲自完成以下事项，并据实更新本节：

- 阅读并解释 `agent.py`、`decision.py` 和 `tools.py` 的职责；
- 检查业务规则是否符合自己的设计判断；
- 使用自己的模型配置完成真实模型测试；
- 根据测试结果修改提示词或错误处理；
- 记录本人修改内容和实际投入时间。

在尚未完成这些工作前，不应把 AI 生成部分描述为纯个人实现。

## 验证结果

AI 辅助生成后实际执行：

```text
python -m pytest --junitxml=examples/test-results.xml
12 passed in 0.33s
```

还执行了 `python scripts/generate_examples.py`，生成 8 组输出和 8 份 Trace。人工抽查确认：

- 冲突时只建议替代时间，不保存；
- 确认后重新检查替代时间；
- 重复执行返回同一草稿；
- 保存失败不会虚报成功。

真实模型验证状态：**未完成，原因是当前环境未配置模型密钥**。
