# 04 AI 辅助使用记录

## 使用范围

本项目允许使用 AI 辅助。本次初始版本由 Codex 协助完成以下工作：

- 将题目拆分为模型决策层、业务工具层和强制约束层；
- 生成 Python 项目骨架、核心循环、CLI 和 OpenAI 兼容接口；
- 生成合成素材、规则、排期与失败注入数据；
- 编写自动化测试、示例生成脚本和项目文档；
- 执行测试并抽查冲突、重复保存和保存失败 Trace；
- 使用候选人在本机配置的 DashScope 凭据运行 `qwen3.5-plus` 真实模型验证。

AI 没有把密钥写入代码、输出或 Trace，没有创建 GitHub 仓库，也没有执行真实发布。

## 候选人贡献

截至当前版本，候选人提供了完整考核要求、选择第 1 题、重置暴露的测试密钥，并在本机完成新密钥配置。核心实现、测试和初始文档主要由 AI 生成。候选人在提交前应亲自完成以下事项，并据实更新本节：

- 阅读并解释 `agent.py`、`decision.py` 和 `tools.py` 的职责；
- 检查业务规则是否符合自己的设计判断；
- 复核真实模型测试结果和超时处理修改；
- 记录本人修改内容和实际投入时间。

在尚未完成这些工作前，不应把 AI 生成部分描述为纯个人实现。

## 验证结果

AI 辅助生成后实际执行：

```text
python -m pytest --junitxml=examples/test-results.xml
15 passed
```

离线生成脚本产生 8 组 Mock 输出和 8 份 Mock Trace；另外通过 API 模式实际生成 8 组 `qwen3.5-plus` 输出和 8 份真实模型 Trace。抽查确认：

- 冲突时只建议替代时间，不保存；
- 确认后重新检查替代时间；
- 重复执行返回同一草稿；
- 保存失败不会虚报成功。

真实模型验证状态：**已完成**。首次正常路径在草稿保存后的最终总结调用发生 30 秒超时，据此将超时调整为 90 秒，并新增保存成功后总结失败的回归测试；重跑后完整通过。
